# Karl Team Workflow

A Codex skill for disciplined multi-agent software delivery:

- task decomposition and disjoint write scopes;
- visible A/B/C workstream coordination;
- daily/nightly acceptance loops;
- blocker ownership and recovery;
- contract, Git, CI, runtime, and release gates;
- truthful handbacks and final reporting.

Install or copy this skill into your Codex skills directory, then invoke it as `$karl-team-workflow`.
